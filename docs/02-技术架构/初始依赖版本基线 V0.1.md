# 初始依赖版本基线 V0.1

## 后端

| 组件 | 锁定版本 |
| --- | --- |
| Java | 17 |
| Spring Boot | 3.5.0 |
| Spring Cloud | 2025.0.0 |
| Spring Cloud Alibaba | 2025.0.0.0 |
| Nacos Server | 3.2.4（已部署） |

Spring Boot 3.5、Spring Cloud 2025.0 与 Spring Cloud Alibaba 2025.0 的组合已通过 Maven 聚合构建验证。Nacos Discovery 在本地默认关闭；配置导入为 optional，连接真实环境时由环境变量注入地址、Namespace 与凭据。

## 前端

| 组件 | 锁定版本 |
| --- | --- |
| pnpm | 10.33.2 |
| Vue | 3.5.13 |
| Vite | 6.1.0 |
| TypeScript | 5.7.3 |
| Arco Design Vue | 2.57.0 |

实际完整依赖树由 `frontend/pnpm-lock.yaml` 固化。升级任一核心依赖前，须重新执行后端聚合构建、前端类型检查和生产构建。
