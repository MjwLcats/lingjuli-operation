# Design System 变更记录

## 2026-10-19 — 商户端首页与驾驶舱分层

- 确认商户端定位为“高效运营工具 + 经营数据驾驶舱”的结合。
- 确认登录后默认进入运营首页：同页提供全局范围、待办与预警、常用运营入口和轻量经营概览。
- 确认完整经营驾驶舱为独立一级菜单，负责趋势、对比、排行、异常归因与带条件下钻。
- 确认运营首页和驾驶舱共享同一套 Token、组件、图标与视觉语言，不创建第二套数据大屏主题。
- 新增《设计系统总则》与《商户端运营首页与经营驾驶舱规范》作为本次决策的权威中文记录。
